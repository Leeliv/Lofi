This is a small experimental project in which im exploring digital signal processing (DSP) to recreate a retro lo-fi sound similar to the fallout sound track and generic lo-fi audios
While this is a DSP project im also using it to pracktice my OOP kowledge so theres that LMAO
Feel free to try it and let me know of anything that can be changed or added
STILL A WORK IN PROGRESS so don't look to hard :)

Current functionality:

  Effects:
    Soft clipping
    Wow and Wobble
    Bit crushing
    Delay and feedback
    Down sampling
    Low pass filter

  CLI:
    add: adds chosen effect to pedal board
    remove: removes chosen effect from pedal board
    bypass: bypasses chosen effect
    pause: pauses
    play: plays
    effect: shows the effect name and chosen parameters for that effect
    set: changes parameters for chosen effect
    list: displays a list of usable effects and their adjustable parameters
